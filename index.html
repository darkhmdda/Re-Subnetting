Subnetting, paso a paso.

Resuelve manualmente los cálculos y usa la comprobación para verificar tus respuestas. La tabla de direcciones se genera automáticamente.

01

Datos del problema

Introduce la dirección de red y selecciona si el ejercicio solicita NSU, NHU, ambos requisitos o notación CIDR.

Modo NSU: se calcularán los bits de subred necesarios y se conservarán al menos 2 bits para hosts.
Modo manual: completa tus cálculos. Los bits de host se obtienen automáticamente según los requisitos seleccionados.
02

Tabla de clases IP

Referencia rápida para identificar la clase y la máscara por defecto.

Clase Primer octeto MSD Uso general
A 1–127* 255.0.0.0 Redes grandes
B 128–191 255.255.0.0 Redes medianas
C 192–223 255.255.255.0 Redes pequeñas
D 224–239 — Multicast
E 240–255 — Reservada / experimental

* Se conserva el rango de los apuntes de clase. En redes reales, 127.0.0.0/8 está reservado para loopback.
